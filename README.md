# Dynamic Peninsula

Music controls, system stats, clipboard history, and Codex and Claude usage at your Mac's notch.

[Download for macOS](https://github.com/zhn66776/dynamic-peninsula/releases/tag/public-2.7.3-20260929)

**macOS 26+ · Apple silicon and Intel · English interface**

The current release is private. Sign in to GitHub to download it.

## Features

- **Music:** playback controls, track information, and visualizations.
- **System monitor:** CPU, GPU, memory, storage, temperature, and fan statistics.
- **Clipboard and Shelf:** clipboard history, file storage, and AirDrop sharing.
- **Codex and Claude:** account usage, remaining quotas, and session statistics.
- **AgentLight:** activity indicators for local coding sessions.

Stock tracking belongs to the separate Personal Build. This download contains Public Release.

## Installation

1. Download and open `Dynamic-Peninsula-2.7.3-public-macOS26-universal.dmg`.
2. Drag `Dynamic Peninsula.app` to `Applications` and open it.
3. For the macOS security prompt, choose **System Settings > Privacy & Security > Open Anyway**. [Apple's instructions](https://support.apple.com/102445).

Signing: **ad-hoc (unnotarized)**.

## Accounts and permissions

At launch, Dynamic Peninsula uses the Mac's saved Codex login and Claude session key to query account usage. Opening an account tab loads local session statistics. Music controls, calendar, camera, and other integrations use macOS permissions.
